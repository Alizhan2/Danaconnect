## Проверки и границы

- 429 API-тестов прошли на одноразовой SQLite без production credentials; в их числе проверки публичных показателей, регистрации и разграничения доступа.
- TypeScript и production-сборка обоих приложений прошли. Прошли существующие suites frontend, date-format, download, mobile-navigation, registration, mentor-offer, demo-mentor, admin-invitation и admin-registration.
- Браузер: три языка на ширинах 320, 390, 768, 1280 px. Проверены текст, название вкладки, порядок/размер рамок логотипов, гостевые действия, меню, Escape и возврат фокуса, сохранение языка; необработанных ошибок JavaScript нет.
- Семь публичных страниц на 390 px вернули HTTP 200, горизонтальной прокрутки нет. Административные экраны входа и приглашения проверены на ширинах 320, 390, 1280 px.
- Главная действительно получала HTTP 200 от временного API `/public-summary` и отображала его нули. Загрузка, некорректный ответ, ошибка и демо-показатели проверены отдельными явно отмеченными browser fixtures.
- Браузер использовал production-сборки в облачной рабочей среде и отдельную пустую SQLite. Это не live-проверка production базы, отправки почты, встреч или частных пользовательских операций.
- Проверка защищённого production URL через Vercel connector вернула `403 forbidden` на шаге `read_protection_bypass`. Проект и последний READY deployment видны; этого недостаточно для подтверждения права публикации. Результат создания preview фиксируется отдельно в PR.
