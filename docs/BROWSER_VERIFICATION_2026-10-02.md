# Браузерная проверка DanaConnect — 2 октября 2026

## Среда и границы

Проверены реальные формы через встроенный браузер Codex. Web и admin используют production-сборки функционального коммита `82d056e` на портах 3100/3101; API — изолированную SQLite на 8002. Исправление названий диалогов проверено после перезапуска API с новым кодом. Для разных сессий использованы `127.0.0.1` и `localhost`.

Все участники, коды, документы, согласия, сообщения, обращения и результаты в этом сценарии синтетические. Документы прямо обозначены как демонстрационные, не юридические. Письма и внешние сервисы отключены. Рабочие учётные записи и юридические согласия не использовались.

## Найденное и исправленное

Несколько диалогов отображались одинаково: «Менторство». API теперь отдаёт имя собеседника; проектные диалоги — название проекта и имя. Учитываются беседы до создания участия. Email и закрытые поля не добавлены в ответ. Новые тесты проверяют обе стороны, разные беседы, пустое имя и отказ доступа постороннему. В браузере после перезапуска API имя ментора появилось в кнопке и заголовке существующего диалога.

После исправления весь изолированный API-набор прошёл: **109 passed**, 0 failed, 262,74 секунды. Сохранилось одно ранее известное предупреждение Starlette/httpx. Фронтенд в этом исправлении не изменён; результаты его прежних 22 проверок и обеих сборок остаются в основном отчёте.

## Что этим не подтверждено

- Это локальная браузерная приёмка перечисленных сценариев. Реальный Google-вход, личный MFA каждого администратора и рабочая регистрация после публикации документов требуют отдельного прохождения.
- Кнопка скачивания данных показала «Копия данных сохранена», API вернул успех. Браузерный механизм ожидания скачивания не получил файл: содержимое фактически скачанного файла этим действием не проверено.
- Попытка установить мобильный viewport 390 px не применилась: DOM оставался 1226 px. Override сброшен; этот снимок не считается мобильной приёмкой.
- Проверено переключение языка страницы сообщений, не все страницы и не качество всех переводов. В используемом браузере казахская дата отображалась с `M10`; полная локализационная приёмка остаётся отдельным пунктом.
- Закрытые материалы, публичная публикация результата, повторяющееся расписание и другие не перечисленные формы в этом браузерном сценарии не пройдены. Их автоматические API-проверки описаны в [основном отчёте](VERIFICATION_2026-10-02.md).
- Правовые документы рабочей базы остаются неопубликованными. Учебные подтверждения не разрешают отправку настоящих анкет.
