# Диагностические письма DanaConnect

Получатель для согласования: личный аккаунт владельца. Отправитель: `danaconnectkz@gmail.com`.
Отправка выполняется только после разрешения владельца. Эти сообщения проверяют SMTP и попадание во входящие. Настоящее приглашение с одноразовой ссылкой и настоящее напоминание о встрече проверяются отдельно при запуске команды.

## Письмо 1

**Тема:** [ТЕСТ] DanaConnect — проверка почты приглашений

Это диагностическое письмо DanaConnect для проверки рабочего отправителя и доставки уведомлений команды.

Настройка приглашений готова: новый администратор получает ссылку, подтверждает email и подключает Authenticator через личный QR-код.

Сообщение не содержит приглашения. Для проверки доставки ответьте в чате Codex, что письмо появилось во входящих или спаме.

## Письмо 2

**Тема:** [ТЕСТ] DanaConnect — проверка почты напоминаний

Это диагностическое письмо DanaConnect для проверки доставки напоминаний.

В рабочем сценарии письмо содержит дату встречи в часовом поясе получателя. Отмена встречи отзывает ещё не отправленное напоминание; просроченное письмо не отправляется.

Это проверка доставки. Для проверки сообщите в чате Codex, что письмо появилось во входящих или спаме.
