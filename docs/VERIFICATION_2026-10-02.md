## Исправления

1. Первый запуск `app.seed --create-tables` пропускал таблицы расширений, включая MFA и почту. Теперь регистрируется вся схема; добавлена проверка запуска в новом процессе и повторного запуска без дубликатов.
2. Админка падала при запрещённом localStorage. Чтение и запись настроек языка имеют fallback.
3. Боковое меню сохраняло старую роль после сохранения анкеты. Успешное сохранение обновляет данные пользователя в оболочке; неудачное не отправляет событие.
4. Добавлены `nosniff`, запрет встраивания в iframe и `strict-origin-when-cross-origin` для страниц обоих интерфейсов.
5. API и frontend тесты включены в GitHub Actions при push/PR; локальная команда API изолирует окружение от рабочих настроек.
